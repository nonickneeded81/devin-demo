# devin-demo
demoing devin
this is a simple python demo app to test devin

it currently:
- prints a welcome message
- asks for name
- birthdate of the user
- picks one american male actor that was born at the same date and shows this to the user
- contains a simple function
- devin can add further features

## How to Run

1. Make sure you have Python 3 installed.
2. Run the app from the project directory:

```bash
python app.py
```

3. Follow the prompts to enter your name and birthdate.
